# glyph11

Glyph11, the hardened HTTP/1.1 parser, on the JVM: genhttp-kt's Kotlin port
(github.com/Kaliumhexacyanoferrat/genhttp-kt, `Glyph11/`, commit a2ad01a), copied in and tuned for Ktron.
The port follows upstream Glyph11 (github.com/dotnet-web-stack/Glyph11).
